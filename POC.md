# Whole-requirement enforcement PoC

This branch is an experimental reference integration, not an upstream-ready
proposal or a production release. It preserves the demonstrated runtime
implementation; the public documentation records its boundaries and limitations.

Start with the [complete PoC guide](https://github.com/vfalico/agentsuite-guardd/tree/poc/whole-requirement-v1/docs/poc).
It contains exact source pins, companion setup, build and test instructions,
demonstrated results and the differences from the proposed upstream design.
Canonical module/import paths are unchanged.
